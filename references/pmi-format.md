# PMI Monthly Report Format Reference

## File Naming

Format: `PMI-YYYY-M.DD~M.DD.md` (e.g., `PMI-2026-3.15~4.14.md`), date range uses start and end dates.

## Content Format

Grouped by project, each project summarized in one sentence. Bilingual: Chinese paragraph first, then English paragraph, separated by one blank line.

```markdown
- 【项目1】中文一句话总结
- 【项目2】中文一句话总结

- Project 1: English one-sentence summary
- Project 2: English one-sentence summary
```

## Rules

- Former names not shown in title (e.g., NativeUSD → TSthUSD, only show TSthUSD)
- Each project one line, concise
- Chinese paragraph first, English paragraph second
- One blank line between Chinese and English paragraphs
- Within the same paragraph, no blank lines between entries
